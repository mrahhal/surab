# Conventions

Braces on new lines.

Indentation uses 4 spaces.

Always append a comma at the end of a list if arguments are listed on new lines.

Naming:

- modules: snake_case
- files: snake_case because a file is a module
- types: PascalCase
- fields and variables: camelCase
- functions and methods: snake_case

Naming conventions should be enforced by the compiler.
