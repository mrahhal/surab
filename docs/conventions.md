# Conventions

Indentation uses tabs.

Braces on same lines.

Always append a comma at the end of a list if arguments are listed on new lines.

Naming:

TL;DR: Everything in snake_case except for types in PascalCase.

- packages: snake_case
- modules: snake_case
- files: snake_case
- types: PascalCase
- fields and variables: snake_case
- functions and methods: snake_case

Naming conventions should be enforced by the compiler.
