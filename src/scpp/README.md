# scpp

scpp ([s]urab [cpp]) is a C++ lib that integrates the llvm and clang C++ libs, and is used in the Surab compiler to generate LLVM IR and compile to machine code.

Before attempting to build scpp, you need to download Surab provided prebuilt llvm+clang archive that matches your system:
